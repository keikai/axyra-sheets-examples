# Axyra guides — Group 6

Two concrete workflows for the Axyra Agent Skill. Each subdirectory is an
independent Java 17+ Maven project. Generated applications use Axyra Sheets at
runtime; they do not require a coding assistant to execute a report.

- `template-report/`: article 22 — Java records populate an Excel template.
- `poi-migration/`: article 23 — a POI report and an Axyra replacement are compared.

Each project pins Axyra Sheets 1.0.0-Beta-Eval. Evaluation marks and notice
content are retained in the supplied workbooks. No license token is included.
