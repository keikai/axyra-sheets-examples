Axyra Excel read/write guide examples

Requirements: Java 17 or later, Maven, and a supported native platform.
Library: io.keikai:axyra-sheets:1.0.0-Beta-Eval
The POM includes the evaluation repository and required plugins.
Microsoft Excel is not required.

FIRST RUN: one main complete example per guide
Open a terminal in this axyra-read-write directory:

mvn -q compile exec:java -Dexec.mainClass=ReadExcelFile
mvn -q compile exec:java -Dexec.mainClass=WriteExcelFile

ReadExcelFile reads input/sales.xlsx, Sales!A1:C4. It prints the header, two
business rows, and a total of 1330.0. For another file with the same layout,
add -Dexec.args="/path/to/file.xlsx"; change sheet/range for other layouts.
WriteExcelFile uses two Sale records and writes output/sales.xlsx. Its total
row is fixed for that fixture. See the AI-generated variant for dynamic rows.

CURRENT SHORT-PROMPT AI RUN
The current guide shows new implementations generated and executed from short,
natural prompts without specifying the expected total. The assistant still had
the existing project and previous examples in context; this is not a blind or
timed trial. The displayed prompts are exactly the files in ai-session-simple/.

mvn -q compile exec:java -Dexec.mainClass=SimpleSkillReader
mvn -q exec:java -Dexec.mainClass=SimpleSkillWriter
mvn -q exec:java -Dexec.mainClass=VerifySimpleSkill

SimpleSkillReader converts rows to Order records, keeps IDs as text, skips
empty rows, and uses the fixture's Total footer as its table boundary.
SimpleSkillWriter writes output/ai-sales-simple.xlsx with numeric amounts,
bold headers, formats, and a SUM formula. VerifySimpleSkill computes expected
values from the input records and compares the reader and saved workbook.

ai-session-simple/ includes the original short prompts, full project context,
raw stdout/stderr, manifest.json with hashes/commands/exit codes, and detailed
expected-actual.json. expected/ai-sales-simple.xlsx is an unchanged copy of the
actual generated workbook. prompts/*.txt mirrors these current short prompts.
The first read/write examples above remain the main complete programs.

EARLIER LONG-PROMPT AI RUN (HISTORY)
These are new classes generated by Codex during the guide-revision session,
with the existing example project, guides, and Axyra Sheets skill in context.
They are distinct from the two earlier reference classes above. This is not a
blind trial, timing study, or guarantee about other AI outputs.

mvn -q compile exec:java -Dexec.mainClass=SkillReadSales
mvn -q exec:java -Dexec.mainClass=SkillWriteSales
mvn -q exec:java -Dexec.mainClass=VerifySkillSession

SkillReadSales discovers the used range, validates the known header schema,
skips empty rows, preserves text IDs, rejects invalid/error values, and stops
at the Total footer. That footer is part of this fixture's contract. It is not
a general business-row detector for arbitrary spreadsheets.
SkillWriteSales uses Order records, derives the total row from list size, and
handles an empty list with a numeric zero total. It writes output/ai-sales.xlsx.
VerifySkillSession reopens the file and checks IDs, types, headers, formula,
number formats, total 1330, edit/reopen total 1580, and an empty-list total of 0.

ai-session/ contains the exact prompts, SESSION.txt context, raw stdout/stderr,
and manifest.json with commands, exit codes, and prompt/source hashes. The
recorded generated code is in src/main/java/SkillReadSales.java and
SkillWriteSales.java. Actual saved AI outputs are in expected/ai-*.xlsx.
The manifest records the installed skill's hash; it does not claim that an
independently installed or later skill version will produce identical code.

READ, UPDATE, CALCULATE, SAVE
mvn -q compile exec:java -Dexec.mainClass=UpdateSalesReport

This changes C2 in the sample from 1250 to 1500, prints 1,580.00, saves
sales-updated.xlsx, and reopens it to check the saved numeric total of 1580.

OPTIONAL ADVANCED RECIPES
mvn -q compile exec:java -Dexec.mainClass=ReadAllWorksheets
mvn -q exec:java -Dexec.mainClass=WriteJsonSalesReport
mvn -q exec:java -Dexec.mainClass=VerifyRevisions
mvn -q exec:java -Dexec.mainClass=VerifyExamples

ReadAllWorksheets scans every worksheet, including evaluation notices. Its TSV
writer keeps blank columns in position and normalizes embedded tabs/newlines.
Use a dedicated delimited-text writer for lossless text export.
DatabaseSalesReport.export(conn, "Q3", Path.of("q3-sales.xlsx")) uses your
existing JDBC connection and driver. writeReport applies date/amount formats
before saving and supports null date/amount values and empty results. Create
parent directories first if choosing a nested output path.
WriteJsonSalesReport registers JavaTimeModule before parsing LocalDate JSON.
The POM includes jackson-datatype-jsr310 2.22.3. Its four-column dated record
schema differs from the opening examples' three-column record schema.
The database writer was tested with Java record fixtures, and SourceRecipes'
JDBC mapping with a synthetic CachedRowSet; no live JDBC server is claimed.
advanced/ retains the longer technical recipe notes outside the guide's main
reading path. expected/ includes observed reference results and transcripts.
visuals/ contains data-flow SVGs built from the workbook evidence, rather than
Excel UI screenshots; ai-session/figure-evidence.json holds the cell values.
